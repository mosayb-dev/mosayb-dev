پروژه‌های زنده و عملیاتی

PROJECT 01 · E-COMMERCE
فروشگاه اینترنتی موبایل و کالای دیجیتال ● نسخه آنلاین فعال

بلو مارکت (Blue Market)

یک پلتفرم فروشگاهی مدرن و کاملاً راست‌چین با بیش از ۱۵۰ محصول داینامیک. این پروژه با تمرکز بر تجربه خرید سریع، دسته‌بندی هوشمند، جستجوی لحظه‌ای و صفحه جزئیات محصول حرفه‌ای پیاده‌سازی شده است.

چالش‌های فنی و راه‌حل‌ها:

  • جستجو و فیلتر آنی سمت کلاینت: پیاده‌سازی موتور فیلتر چندگانه و سرچ زنده با Vanilla JavaScript بدون نیاز به رفرش صفحه.
  • مدیریت وضعیت سبد خرید: ذخیره‌سازی پایدار اقلام سبد خرید و تنظیمات کاربر در LocalStorage.
  • طراحی Mobile-First: بهینه‌سازی چیدمان کارت‌های محصول و منوها برای نمایش بی‌نقص در موبایل و دسکتاپ.
HTML5 CSS3 Vanilla JavaScript Bootstrap 5 LocalStorage Responsive UI

PROJECT 02 · BOT & WEB SYSTEM
سامانه یکپارچه اتوماسیون خدمات کافی‌نت ● ربات تلگرام فعال

کافی‌نت مهندس (CafeNet Engineer)

سیستم جامع پذیرش و مدیریت سفارش‌های آنلاین شامل ربات تلگرامی مشتریان و داشبورد مدیریت تحت وب. مشتریان بدون نیاز به مراجعه حضوری می‌توانند خدمات مورد نظر را انتخاب، مدارک را ارسال و وضعیت سفارش را پیگیری کنند.

چالش‌های فنی و راه‌حل‌ها:

  • معماری دوگانه ربات و پنل وب: اتصال ربات تلگرام پایتونی به دیتابیس SQLite و API سمت سرور (FastAPI) برای همگام‌سازی لحظه‌ای سفارش‌ها.
  • مدیریت جریان مکالمه (State Machine): طراحی منوهای مرحله‌به‌مرحله برای ثبت سفارش، ارسال رسید پرداخت و رزرو نوبت حضوری.
  • سیستم تیکتینگ و پیگیری: امکان ارسال پیام پشتیبانی و مشاهده وضعیت هر سفارش با کد رهگیری اختصاصی.
Python Telegram Bot API FastAPI SQLite Admin Dashboard HTML/CSS/JS
