علاقه‌مند به ساختن در دنیای وب

من دانشجوی مهندسی کامپیوتر و علاقه‌مند به توسعه وب هستم. در مسیر یادگیری، روی طراحی و پیاده‌سازی وب‌سایت‌ها و ابزارهای کاربردی کار می‌کنم و تلاش دارم با تمرین روی پروژه‌های واقعی، مهارت‌های فنی و نگاه محصول‌محور خودم را تقویت کنم.

به کدنویسی تمیز، رابط کاربری قابل‌فهم، طراحی واکنش‌گرا و حل مسئله اهمیت می‌دهم و از همکاری در پروژه‌های چالش‌برانگیز استقبال می‌کنم.

PROJECT 01
فروشگاه اینترنتی موبایل و کالای دیجیتال

بلو مارکت (Blue Market)

یک فروشگاه اینترنتی کامل و داینامیک با بیش از ۱۵۰ محصول. این پروژه شامل سیستم فیلتر و دسته‌بندی پیشرفته، جستجوی زنده، اسلایدر محصولات، بخش نظرات مشتریان و رابط کاربری کاملاً راست‌چین (RTL) است. چالش اصلی این پروژه، مدیریت داینامیک دیتای حجیم محصولات (از طریق آرایه‌های جاوااسکریپت) و هماهنگ‌سازی انیمیشن‌های UI بدون افت سرعت سایت بود.

HTML5 CSS3 Vanilla JS Bootstrap 5 Responsive Design E-Commerce UI DOM Manipulation

چالش‌های فنی و راه‌حل‌ها:

  • پیاده‌سازی فیلتر و سرچ زنده با Vanilla JavaScript بدون استفاده از بک‌اند.
  • مدیریت حالت‌های (States) سبد خرید در LocalStorage.
  • طراحی کاملاً واکنش‌گرا (Mobile-first) با استفاده از Grid و Flexbox.
